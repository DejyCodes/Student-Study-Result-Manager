# Student Study & Result Manager

A Python-based student management system designed to manage student information, study sessions, and academic results.

## Features

* Add and view students
* Update student information
* Delete students
* Search students
* Add, update, and delete results
* Calculate student averages
* Add and view study sessions
* Delete study sessions
* Simple menu-based interface

## Technologies Used

* Python
* Object-Oriented Programming (OOP)
* File Handling

## Project Purpose

This project was created as a practical Python project to manage student study information and academic results while applying programming concepts in a real-world application.
